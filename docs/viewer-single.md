# 뷰어 하나만 보기 (2026-11-27, rust 가지, 릴리스 전)

주인 말: "프리뷰가 필요 없을 때는 하나만 켜서 작업공간을 확보할 수 있게 해."

## 쓰는 법

- 보기 방식 둘: **둘 다**(다음 · 송출 중, 기본) / **송출 중만**.
- 바꾸는 곳
  - 가운데 '보기' 머리 오른쪽 구획 단추 [둘 다 | 송출 중만]
  - 보기 메뉴 → '뷰어: 둘 다 · 송출 중만 바꾸기 (본문 자리 넓히기)'
  - 단축키 **Ctrl+Shift+L** (설정 → 단축키 '뷰어 보기: 둘 다 · 송출 중만 바꾸기' 에서 바꿀 수 있음, 메뉴 안내도 따라 바뀜)
- 고른 방식은 설정 `rsProLayout.viewerMode` ("both" | "live") 에 저장되어 다음 실행에도 그대로. 보기 → 배치의 '기본값' 은 rsProLayout 전체를 비우므로 둘 다로 돌아간다.
- 설정 → 조작 화면 **'바로 송출 모드에서는 자동으로 송출 뷰어만'** (`ui.directLiveOnly`, 기본 켜짐): 미리보기를 끄면(바로 송출) 저절로 송출 중만. 그동안 단추·단축키로 '둘 다' 를 고르면 이번 바로 송출 동안만 둘 다(저장 안 함, `App::viewer_direct_both`). 미리보기 모드로 돌아오면 원래 고른 방식.

## '송출 중만' 일 때 화면

```text
│ 큐시트 판 │ 본문 · 편집 (위에서 아래까지)        ║ 보기 [둘 다|송출 중만] │ 인스펙터 │
│           │  편집칸                              ║ 송출 중 뷰어 (빨강)    │          │
│           │  ─────                               ║ 지금 화면 · 슬라이드 줄│          │
│           │  본문 목록                           ║ 다음 [작은 그림] ◀ n/m ▶│          │
```

- 송출 뷰어 칸은 가운데 판 폭의 36% (260px 이상, 경계 띠를 끌어 25~60%, `rsProLayout.liveW`).
- 미리보기 뷰어와 그 슬라이드 줄은 숨긴다. 대신 송출 뷰어 아래 **노랑 '다음' 줄**(미리보기 모드일 때만): 작은 그림(노랑 테두리) · 제목 · ◀ n/m ▶(PageUp/PageDown 과 같음). 작은 그림을 오른쪽 클릭하면 예전 미리보기 화면 오른쪽 클릭 메뉴(송출 · 이전/다음 슬라이드 · 다음/이전 순서 미리보기 · …), 두 번 누르면 송출.
- 순서 · 절을 누르면 '다음' 으로 올라가는 동작, F9 · PageUp/Down · ←→ · Enter, 위 상태 표시창 '다음 · …', 큐시트 노랑 줄은 그대로. 미리보기 슬라이드는 아래 본문 목록에서도 고른다(예전과 같음).
- 미리보기 뷰어의 출력 고르기 [예배당 | OBS | 추가 출력] 는 미리보기 그림을 어느 출력 모양으로 볼지 고르는 것이라, 뷰어가 없으면 쓸 데가 없어 '다음' 줄은 예배당 모양으로만 그린다.
- 본문 판이 좁아지면(620px 미만) 편집칸 머리의 글자 단추(슬라이드 편집 · 복제 · 순서 삭제 · 크게)를 아이콘만으로(이름은 툴팁) — 1000x640 에서 제목을 덮던 것.
- 편집칸 '크게' 일 때는 예전처럼 본문 판이 가운데 전체.

## 배치를 고른 까닭 (두 가지를 실제로 띄워 비교)

같은 자료(요3:1-36 성경봉독을 송출, 편집칸 열림)를 `node tools/viewers/shots.js` 로 찍어 본문 목록에 보이는 절 수를 셌다.

| 창 크기 | 둘 다 (지금) | 가) 오른쪽 칸 · 본문 전체 높이 | 나) 뷰어 줄 높이만 줄임 |
|---|---|---|---|
| 1000x640 | 0.5절 | **2.5절** | 0절 (편집칸만 보임) |
| 1600x960 | 1.5절 | **5절** | 3절 |
| 1920x1080 | 3절 | **8절** | 4절 |

가) 를 골랐다. 뷰어 줄을 낮춰도 송출 화면이 16:9 라 한 줄 높이가 크게 줄지 않고, 그 줄의 왼쪽 자리는 비게 된다. 오른쪽 칸으로 옮기면 본문 · 편집칸이 판 높이를 다 쓰고(편집칸 46% 도 함께 커짐), 오른쪽 칸 아래 남는 자리에는 '다음' 줄이 들어간다. 대신 본문 폭이 줄어 긴 절이 두세 줄로 접히지만, 그래도 세 크기 모두 가) 가 더 많이 보였다.
