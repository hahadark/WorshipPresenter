# OBS 설정 가이드 (워십프리젠터 2.x)

> 2.x는 Windows와 맥(애플 실리콘)에서 주소와 방법이 같습니다. 1.x(Electron 판)를 쓰신다면 [1.x OBS 설정 가이드](v1/OBS설정가이드.md)를 보세요.

워십프리젠터는 이 PC 안에서만 동작하는 웹 서버(127.0.0.1)를 엽니다. OBS는 그 화면을 **브라우저 소스**로 받아 표시합니다.
성경 본문·찬양 가사·찬송가 악보·공지·영상 등 송출 화면이 바뀌면 OBS 화면도 바로 바뀝니다. 새로 고치거나 다시 등록할 필요가 없습니다.

1.x에서 쓰던 주소가 2.x에서도 같습니다. 1.x에서 2.x로 바꿔 설치했다면 OBS는 그대로 두어도 됩니다.

## 주소

| 용도 | 주소 |
|---|---|
| 예배당 화면 그대로 (전체 화면) | `http://127.0.0.1:37528/outputs/main` |
| 투명 자막 (카메라 화면 위에 얹기) | `http://127.0.0.1:37528/outputs/overlay` |
| 무대 화면 (설교자·찬양팀 모니터) | `http://127.0.0.1:37528/outputs/stage` |
| OBS 조작 도킹 (OBS 안의 작은 조작판) | `http://127.0.0.1:37528/dock` |

- 주소는 **설정(오른쪽 위 톱니) → OBS · 방송 자막**에 모두 나와 있고, [복사] 단추로 복사할 수 있습니다.
- 포트(37528)는 같은 곳의 고급 항목 **로컬 서버 포트**에서 바꿉니다. 다른 프로그램과 겹칠 때만 바꾸세요. 바꾸면 프로그램을 다시 켜야 하고, OBS에 넣어 둔 주소도 바꿔야 합니다.

## 브라우저 소스 추가하기

1. OBS → 장면 선택 → 소스 `+` → **브라우저**
2. 이름: `워십프리젠터 자막` (자유롭게)
3. 설정
   - **URL**: `http://127.0.0.1:37528/outputs/overlay`
   - **너비 / 높이**: `1920` / `1080` (템플릿 해상도와 같게. 4K 템플릿이면 3840 / 2160)
   - **사용자 지정 CSS**: 비워 두거나 OBS 기본값 그대로 둡니다.
   - **소스가 보이지 않을 때 종료**: 끄기를 권장합니다. 켜 두어도 다시 연결되면 최신 화면을 받습니다.
   - **장면이 활성화될 때 브라우저 새로 고침**: 끄기
4. 확인을 누른 뒤 소스를 화면 크기에 맞춥니다 (`Ctrl+F` 화면에 맞추기).

예배당 화면과 똑같은 전체 화면이 필요하면 같은 방법으로 `/outputs/main` 을 추가합니다.

## 동작

- 송출(F9 · 더블클릭 · 바로 송출 모드에서 클릭)하면 OBS 화면이 바로 바뀝니다.
- 전환 효과(디졸브·컷)는 하단 **빠른 설정**의 **전환**에서 출력마다 고릅니다.
- 찬송가·찬양 PPT를 OBS 자막에 내보낼 때는 빠른 설정의 **PPT 슬라이드: 그림 그대로 / 가사만** 중에서 고릅니다. **가사만**이면 악보 그림 없이 가사 글자만 나갑니다.
- 영상 순서의 **소리는 예배당 화면 창에서만** 납니다. OBS 브라우저 소스는 소리 없이 화면만 맞춰 재생합니다. 방송에 소리를 넣으려면 OBS에서 PC 소리(데스크톱 오디오)를 잡으세요.
- 연결이 끊기면 마지막 화면을 그대로 둔 채 자동으로 다시 연결하고, 연결되면 최신 송출 상태를 다시 받습니다. 워십프리젠터를 다시 켜도 주소는 같습니다.

### 투명 자막을 바꾸는 두 가지 방식

**보기** 메뉴에서 켜고 끕니다. 설정 → OBS · 방송 자막에도 같은 항목이 있습니다.

- **OBS 자막: 슬라이드 그대로** — 켜면 투명 자막 주소에도 자막 템플릿 대신 예배당 화면과 같은 슬라이드가 나갑니다. 프로그램을 다시 켜면 꺼집니다.
- **OBS 자막: 그림 슬라이드 작게** — 악보·그림 슬라이드를 방송 화면 오른쪽 위에 작게 보여 줍니다. 가사가 있으면 가사는 아래 자막으로 나갑니다.

## 연결 확인

조작 화면 맨 아래 오른쪽에 출력마다 연결 상태가 점과 글로 나옵니다.

- `OBS 자막 1개 동기화됨` (초록): OBS가 최신 송출 내용을 받아 표시했다고 응답한 상태
- `OBS 자막 1개 갱신 대기` (노랑): 아직 응답을 받지 못한 상태. 잠시 뒤에도 그대로면 OBS 소스를 확인하세요.
- `OBS 자막 연결 없음` (회색): 그 주소로 연결된 OBS 소스가 없음

`OBS 전체`(`/outputs/main` 을 넣은 브라우저 소스)도 같은 방식으로 표시됩니다.

## 자막 디자인 바꾸기

OBS 자막은 두 가지 템플릿을 씁니다.

- **성경·공지**용: 기본값 `투명 출력 (OBS 자막)`
- **찬송가·찬양 가사**용: 기본값 `찬송가·찬양 두 줄 (OBS 자막)`

바꾸는 곳은 세 군데입니다. 어느 곳에서 바꿔도 결과는 같습니다.

1. **빠른 설정**: 위쪽 대상에서 **OBS 성경** 또는 **OBS 찬송가**를 고른 뒤 템플릿을 고릅니다. 기존 템플릿을 건드리지 않고 고치고 싶으면 [복제]로 복사본을 만들어 건 다음 [자세히 ▸]로 고칩니다.
2. **설정 → OBS · 방송 자막**: `OBS 자막 템플릿 — 성경·공지`, `OBS 자막 템플릿 — 찬송가·찬양`
3. **보기 → 출력 테마 관리**: 테마를 고르고 적용할 출력(OBS 자막, OBS 찬송가·찬양)에 체크한 뒤 **고른 출력에 적용**. 마음에 들지 않으면 되돌릴 수 있습니다.

템플릿 편집(**보기 → 출력 템플릿 편집**)에서 자주 고치는 항목입니다.

- 하단 자막 위치: 세로 배치를 아래로 두고 아래·위 여백으로 조정
- 자막 뒤 반투명 상자: 본문 뒤 상자
- 밝은 영상 위에서 잘 보이게: 외곽선 두께 2~3px, 그림자

저장하면 바로 OBS 화면에 반영됩니다.

## OBS 안에 조작판 넣기 (도킹)

OBS 화면 안에서 송출을 넘기고 지울 수 있는 작은 조작판입니다.

1. OBS → **도킹 → 사용자 지정 브라우저 독**
2. 이름은 `워십프리젠터`, URL은 `http://127.0.0.1:37528/dock` (설정 → OBS · 방송 자막 → **OBS 조작 도킹**에서 복사)
3. 적용하면 OBS 안에 조작판이 생깁니다. 원하는 자리로 끌어다 붙이세요.

## OBS 원격 조작 (방송·녹화·장면을 워십프리젠터에서)

1. OBS 28 이상 → **도구 → WebSocket 서버 설정** → **WebSocket 서버 사용**을 켭니다. 포트(기본 4455)와 비밀번호를 확인합니다 ('연결 정보 표시').
2. 워십프리젠터 **도구 → OBS 원격 조작**에서 **OBS 원격 조작 쓰기**를 켜고 주소(같은 PC면 `127.0.0.1`)·포트·비밀번호를 넣은 뒤 **저장**, **연결 확인**을 누릅니다.
3. 연결되면 그 창에 지금 장면과 방송·녹화 상태가 보이고, 장면 바꾸기와 방송·녹화 시작·끝내기를 할 수 있습니다.
4. 큐시트 순서마다 편집칸의 **⚡ 송출할 때 자동으로**에서 OBS 동작(장면·방송·녹화)을 정해 두면, 그 순서를 송출할 때 OBS가 같이 움직입니다. 예: '설교' 순서 → 장면 '설교 카메라'.

OBS가 다른 PC에 있으면 주소에 그 PC의 IP를 넣고, 그 PC 방화벽에서 OBS를 허용하세요.

## 다른 PC의 OBS로 보내기 (내부망 출력)

방송 PC가 따로 있으면 **도구 → 내부망 출력 (다른 PC 의 OBS)**에서 **내부망 출력 켜기**를 켭니다. 그 창에 예배당 화면·투명 자막·무대 화면 주소가 열쇠(접속 키)가 든 채로 나옵니다. 복사해서 방송 PC의 OBS 브라우저 소스에 넣으세요. 열쇠가 없는 주소로는 열리지 않습니다. 주소가 밖으로 새었다면 [새 열쇠]로 바꾸고, 쓰지 않을 때는 꺼 두세요.

## 보안

- 기본 서버는 127.0.0.1(이 PC)에서만 요청을 받습니다. 다른 PC나 인터넷에서는 접속할 수 없습니다.
- 다른 기기에서 쓰는 기능(휴대폰 리모컨, 내부망 출력)은 켰을 때만 따로 열리고, 리모컨은 PIN(5번 틀리면 30초 동안 막힘), 내부망 출력은 열쇠가 든 주소가 있어야 합니다. 끄면 닫힙니다.
- 일반 웹사이트가 이 PC의 워십프리젠터를 조작하는 것은 막혀 있습니다.

## 아직 확인 중인 것

2.x의 OBS 연결은 자동 시험과 이 PC 안의 시험으로 확인했습니다. 교회마다 다른 실제 방송 장비 구성에서의 시험은 계속하고 있습니다. 문제가 있으면 [이슈](https://github.com/hahadark/WorshipPresenter/issues)로 알려 주세요.
