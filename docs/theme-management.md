# 출력 테마 관리 (2026-11-16)

사용자 요청: "설정 기능이 약해 그리고 테마 관리 기능도 보완해" 가운데 **테마 관리** 부분.
여기서 '테마'는 예배당 화면·OBS 자막에 나가는 **출력 디자인 묶음**이다. 프로그램 화면 색(다크·라이트)과는 다르며, 창 머리말에도 그렇게 적었다.

관련 파일: `crates/wp-core/src/themes.rs`(코어), `crates/wp-app/src/theme_ui.rs`(창), `crates/wp-app/src/theme_ui_tests.rs`(합성 입력 시험).

## 1. 원본(Electron 판) 대조

| 항목 | 원본 `src/core/themes.js` · `core.js` · `web/control/settings.js` | Rust 판 (이번 작업 뒤) |
|---|---|---|
| 기본 테마 | 구세군 5 + 방송 스타일 5, 테마마다 예배당(main)·OBS 자막(overlay) 한 쌍. 템플릿 id `theme-<id>-<출력>` | 같음 (`data/themes.json`, `list_themes()` 그대로) |
| `applyTheme` | 테마 템플릿을 **처음 모양으로 덮어쓴 뒤** 출력에 지정. outputs 가 비면 main+overlay | `apply_theme()` 그대로 (계약 유지). 화면은 이것을 쓰지 않고 `apply_theme_ex(Keep)` 를 쓴다 |
| `ensureTheme` | 순서별 테마: 없으면 만들고 id 를 돌려줌 | 같음 + 내 테마 id 도 받는다 (있는 템플릿 id 만 돌려줌) |
| OBS 찬송가·찬양 칸(overlayLyrics) | 테마와 무관 (따로 고름) | 기본 테마는 그대로 무관. 내 테마만 세 칸을 가질 수 있다 |
| 사용자 테마 · 복제 · 이름 · 삭제 · 찾기 | 없음 | 추가 (원본에 없는 기능) |
| 적용 되돌리기 · 처음 디자인으로 확인 | 없음 (적용하면 고친 것이 말없이 사라짐) | 추가 |
| 가져오기 · 내보내기 | 없음 | 추가 |

원본에 없는 기능이므로 '원본과 동일'로 세지 않는다. 원본과 달라진 **기본 동작**은 하나다: 테마 창의 적용이 더는 고친 템플릿을 덮어쓰지 않는다.

## 2. 안전 원칙

1. **누르는 것은 미리보기뿐.** 카드·견본 글·거르기·출력 고르기는 설정을 바꾸지 않는다. 출력은 '고른 출력에 적용'을 눌러야 바뀐다.
2. **비파괴 적용.** 일반 적용(`ApplyMode::Keep`)은 이미 있는 템플릿을 그대로 두고 출력 지정만 바꾼다. 처음 디자인으로 되돌리는 것은 '처음 디자인으로…' → 확인을 거친 `restore_original` 뿐이다.
3. **출력 범위를 명시.** 예배당 화면 · OBS 자막 · OBS 찬송가·찬양 자막을 체크로 고른다. 찬송가 칸은 기본으로 꺼져 있고, 기본 테마에는 그 디자인이 없어 고를 수 없다. 고르지 않은 칸은 절대 바뀌지 않는다. 적용이 LIVE 에 바로 반영된다는 안내를 단추 위에 둔다.
4. **되돌리기는 건드린 것만.** `ApplyUndo` 는 바꾼 출력 칸의 전 값과 덮거나 새로 넣은 템플릿의 전 모양만 담는다. 그 사이 바뀐 다른 설정은 덮지 않는다. 창을 닫아도 남지만 프로그램을 끄면 사라진다.
5. **내 테마는 늘 새 id.** 저장·복제·가져오기는 템플릿을 `tpl-ct-…` 새 id 로 복사한다. 원래 템플릿·기본 테마·지금 출력은 바뀌지 않는다. 같은 이름이면 `(2)` 를 붙인다.
6. **기본 테마 보호.** 이름 바꾸기·삭제 불가(코어에서도 거절). 고치려면 '복제해서 수정'.
7. **삭제는 묶음 기록만.** 내 테마를 지워도 그 템플릿은 지금 출력이나 큐시트 순서가 쓰고 있을 수 있으므로 '출력 템플릿'에 남긴다 (거기서 따로 지울 수 있고, 쓰는 중이면 그쪽 보호가 막는다).
8. **내보내기에는 디자인만.** 파일에는 `format · version · exportedAt · theme{name, desc, slots} · linkedFiles · note` 뿐이다. 템플릿도 기본 칸만 골라 담는다. API 키·OBS 암호·큐시트·기록 등 다른 설정은 구조상 들어갈 수 없다. 그림·영상·로고는 **경로만** 들어가고 파일은 들어가지 않는다.
9. **가져오기는 검사 뒤 한 번에.** 크기 1MB 이하, JSON, `format = worshippresenter-theme`, `version` 1, 이름 있음, 출력 디자인 하나 이상. 템플릿은 기본 칸·같은 종류의 값만 받고 크기·글자 크기를 범위로 맞춘다. 하나라도 틀리면 설정은 바뀌지 않는다. 파일에 적힌 id 는 쓰지 않으므로 기본 테마나 있던 테마를 덮을 수 없다. 가져온 뒤 그 테마가 가리키는 파일이 이 PC 에 있는지 목록으로 보여 준다.

## 3. 저장 모양

`settings.json` 에 `customThemes` 배열이 하나 늘었다 (없으면 없는 대로 동작, 모르는 다른 칸은 그대로 보존).

```json
"customThemes": [
  { "id": "ct-…", "name": "주일 낮 예배", "desc": "", "createdAt": "…", "updatedAt": "…",
    "slots": { "main": "tpl-ct-…-main", "overlay": "tpl-ct-…-overlay", "overlayLyrics": "tpl-ct-…-overlayLyrics" } }
]
```

템플릿 본체는 기존 `templates` 에 있다 (`theme` 칸에 테마 id). 그래서 템플릿 편집 창에서 고치면 테마에 바로 반영되고, 다른 테마를 적용했다 돌아와도 고친 값이 남는다.

## 4. 사용 흐름

- 보기 → 테마: 왼쪽 목록(내 테마 → 기본 테마 묶음), 이름 찾기, 모두/기본 테마/내 테마, 견본 글(성경·찬양·공지).
- 카드를 누르면 오른쪽에 출력별 미리보기와 '지금 쓰는 출력' 배지. 고쳐 쓴 기본 테마는 '고침' 표시.
- 적용: 출력 고르기 → '고른 출력에 적용' → 결과 글 옆 '적용 되돌리기'.
- '지금 출력 디자인을 내 테마로 저장': 이름(·설명) 입력 → 세 칸의 지금 디자인을 묶어 저장 (출력은 그대로).
- 기본 테마 '복제해서 수정' / 내 테마 '복제' · '이름·설명 바꾸기' · '삭제'(확인) · '디자인 편집: 예배당 / OBS 자막 / OBS 찬송가·찬양'.
- '내보내기…' / '테마 파일 가져오기…'.
- 큐시트 순서의 '테마' 고르기에도 내 테마가 나온다.

### 연결점 (메인 통합용)

- `ThemeUi::take_edit_request() -> Option<String>`: '디자인 편집'을 누르면 템플릿 id 를 한 번 돌려준다. `track_c` 가 프레임마다 불러 `templates.open_with(&id)` 로 이어야 편집 창이 열린다. **아직 잇지 않았다** (`track_c.rs` 는 설정 작업자 소유).
- `app.rs` 순서 편집칸의 테마 고르기를 `themes::list_all` + `theme_ui::apply_item_theme` 로 바꿨다 (공유 파일, 작은 변경).
- 점검용 실행 인자 `--open-themes`: 켜자마자 이 창을 연다 (스크린샷용).

## 5. 시험

- 코어 `themes::manage_tests` 4개: 일반 적용은 고친 것 보존·원복은 명시적 / 되돌리기는 건드린 칸·템플릿만 / 내 테마 저장·복제·이름·삭제·모르는 칸 보존·다시 읽기 / 내보내기에 비밀 없음·가져오기 검사 10가지 실패 시 설정 불변·기본 테마 id 흉내 무해.
- 화면 `theme_ui::tests` 6개 (그린 단추 자리를 합성 입력으로 누름): 미리보기는 상태 불변 / 출력 범위별 적용과 되돌리기 / 일반 적용 보존과 원복 확인 / 저장·복제·이름·삭제 확인·편집 요청 / 내보내기·가져오기 / 1280×720·900×640 에서 가로 잘림 없음.
- 그림은 `paint_slide` 만 쓴다 (미리보기·LIVE 와 같은 그림).
- 점검 실행은 `WP_LEGACY_DATA` 를 빈 폴더로 두고 `--data <임시>` 로 한다. 그러지 않으면 임시 폴더에 bible.db 가 없을 때 1.x 자료와 설정을 복사해 와서 그 설정(리모컨·업데이트 확인 등)으로 켜진다.

## 6. 남은 점

- '디자인 편집' 단추는 `track_c` 연결 전까지 창을 열지 못한다 (요청만 쌓임).
- 720p 에서는 오른쪽 칸을 스크롤해야 적용 단추가 보인다 (미리보기가 위에 있어서).
- 되돌리기는 한 단계이고 프로그램을 끄면 사라진다.
- 내 테마를 지우면 템플릿이 '출력 템플릿'에 남는다 (정리는 사용자가 따로).
- 가져온 테마의 그림·영상·로고 파일은 옮겨 오지 않는다. 없으면 배경이 비어 보인다.
- 기본 테마에는 OBS 찬송가·찬양 디자인이 없다.
- 영어 화면: 문구는 넣었지만 내 테마 템플릿 이름의 출력 꼬리표(예배당 등)는 한국어로 저장된다.
- 실제 예배당 창·OBS 로 나가는 웹 출력과의 나란히 비교(`tools\parity\run.ps1`)는 이번에 돌리지 않았다. 템플릿 모양·출력 데이터는 바꾸지 않았다.
