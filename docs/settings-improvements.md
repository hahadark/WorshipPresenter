# 설정 센터 보완 기록 (2026-11-16)

사용자 요청: "설정 기능이 약해 그리고 테마 관리 기능도 보완해" 중 **설정 화면** 부분.
테마 관리(theme_ui.rs · wp-core/themes.rs)는 다른 작업 갈래가 맡았고 이 문서 범위가 아니다.

고친 파일: `crates/wp-app/src/settings_ui.rs`(센터 본체) · `settings_items.rs`(항목 목록·검색·한 칸 고치기) ·
`settings_keys.rs`(단축키 쪽) · `settings_center_tests.rs`(합성 입력 시험) · `track_c.rs`(연결) · `crates/wp-core/data/en.json`(번역 167개).
소유 밖 파일에 넣은 것은 시험용 몇 줄뿐이다: `app.rs`(시험 모듈 선언 3줄), `tools_ui.rs` · `trackd_ui.rs`(`#[cfg(test)] close_for_test`).
코어(`wp-core`의 settings · updates)는 고치지 않았다.

## 1. 원본(Electron `src/web/control/settings.js`)과 대조

원본 설정 창은 탭 7개(기본 · 테마 · 출력 · 템플릿 · 단축키 · 데이터 · 정보)에 모든 것을 모았다.
Rust 판은 같은 기능이 도구 메뉴와 여러 창에 흩어져 있었고, 설정 창에는 4탭(일반 · 출력 · 단축키 · 조작 화면)만 있었다.

| 원본 설정의 항목 | 고치기 전 Rust 판 | 지금 설정 센터 |
|---|---|---|
| 기본: 화면 언어 | 설정 → 조작 화면 | 조작 화면 → Language · 언어 |
| 기본: 기본 검색 방식 · 분할 방식/절 수 · 범위 끝에서 | 설정 → 일반 | 송출 · 검색 · 분할 (지금 값 · 기본값 표시) |
| 기본: 큐시트 끝에서 다음 순서 · 글자만 숨기기 | 설정 → 일반 | 송출 · 검색 · 분할 |
| 기본: 예배 진행 시계 (cueTimes) | **설정에 없음** (큐시트 관리 쪽에만) | 송출 · 검색 · 분할에 추가 |
| 기본: 한글 입력 자동 전환 | 설정 → 단축키 탭에 섞여 있음 | 송출 · 검색 · 분할 |
| (Rust 판 고유) 미리보기를 거쳐 송출 | 설정 → 일반 | 송출 · 검색 · 분할 |
| 출력: 출력 모니터 · 전체 화면 켜기/끄기 · 창으로 보기 | 보기 메뉴 → 출력 설정 창 | 예배당 출력 → 상태 한 줄(켜짐/꺼짐 · 모니터 이름) + '출력 설정 열기' |
| 출력: 커서 숨김 · 송출하면 자동 켜기 · OBS 같이 숨기기 | 설정 → 출력 (그리고 출력 설정 창) | 예배당 출력 |
| 출력: 출력별 템플릿 3칸 (예배당 · OBS 성경/공지 · OBS 찬송/찬양) | 보기 메뉴 2칸(찬송/찬양 칸 없음) · 빠른 설정 | 예배당 출력 1칸 + OBS 2칸 — **설정에서 고르는 칸이 없던 것을 추가** |
| 출력: OBS 브라우저 소스 주소 복사 (전체 · 자막) | 보기 메뉴 안 | OBS · 방송 자막 → 주소 3줄(전체 · 자막 · 무대)과 복사 단추 |
| 출력: OBS 도킹(/dock) 주소 | 없음 (Rust 서버에 /dock 이 없다) | **넣지 않음** — 서버에 없는 주소를 보여 줄 수 없다 |
| 출력: 내부망 출력 켜기 · 포트 | 도구 메뉴 → 내부망 출력 창 | OBS(고급 접기) · 원격 → 상태(켜짐·포트) + 열기 |
| 출력: 로컬 서버 포트 | **없음** | OBS → 고급 설정(접힘) → 로컬 서버 포트 (다시 켜야 적용된다고 안내) |
| 출력: 출력 연결 상태 | 머리 줄 상태 점 | 센터에는 넣지 않음 (머리 줄 · 연결 점검 창이 이미 보여 준다) → '연결 점검 열기' 연결 |
| 출력: 로고 화면 그림 | 설정 → 출력에 **글칸**(주소를 손으로 써야 함) | 예배당 출력 → 그림 고르기… · 지우기 · 지금 파일 이름 |
| 테마 탭 (묶음별 테마 고르기) | 보기 메뉴 → 테마 고르기 창 | 예배당 출력 → '테마 고르기 열기' |
| 템플릿 탭 (편집 · 복제 · 새로 · 삭제) | 보기 메뉴 → 출력 템플릿 편집 창 | 예배당 출력 → 템플릿 수 + '템플릿 편집 열기' |
| 단축키: 기능별 키 · 저장 · 기본값으로 | 설정 → 단축키 (글칸 23줄 · 기본값 안 보임 · 초기화 확인 없음) | 단축키 → 찾기 · 기본값 열 · 충돌 요약 · 하나씩/전부 기본값(확인 · 되돌리기) |
| 단축키: 다른 프로그램 키 · 전역 단축키와 등록 상태 | 설정 → 단축키 | 단축키 (그대로, 설명 추가) |
| 데이터: 베들레헴 · 번역본 가져오기 · 설치된 번역본 | 파일 메뉴 → 성경 번역본 가져오기 창 | 성경 · 주석 데이터 → 번역본 수 · 지금 번역본 + 열기 |
| 데이터: 주석서 | 보기 메뉴 → 주석 창 | 성경 · 주석 데이터 → 주석서 수 + 열기 |
| 데이터: 여러 PC 동기화 · 자동 백업 | 파일 메뉴 → 동기화 · 백업 창 | 백업 · 동기화 → 동기화 폴더 · 백업 수 + 열기 |
| (Rust 판) 큐시트 관리 · 사용 기록 | 큐시트 · 파일 메뉴 | 백업 · 동기화 → 열기 |
| (Rust 판) 리모컨 · 스트림덱 · Companion/장비 · 카메라 · OBS 원격 | 도구 메뉴 | 원격 · 장비 연결 / OBS → 상태 한 줄 + 열기 (PIN · 비밀번호 · 키 값은 보이지 않음) |
| 정보: 버전 · 지금 확인 · 건너뛰기 취소 | 도움말 → 새 버전 확인 창 | 정보 · 업데이트 → 버전 · (건너뛴 버전이 있으면) 건너뛰기 취소 · '업데이트 창 열기' |
| 정보: 켤 때 새 버전 확인 · 익명 사용 통계 | 업데이트 창 안에만 | 정보 · 업데이트에 추가 |
| 정보: 출처 · 저작권 · 라이선스 | 도움말 → 정보 창 | 정보 · 업데이트 → '정보 · 라이선스 열기' |

따로 있는 창의 기능은 센터에 다시 만들지 않았다(같은 값을 두 군데서 고치면 서로 덮는다). 센터는 **찾는 곳**이고,
각 창은 **하는 곳**이다.

### 바로잡은 것

- **"Rust 판은 아직 … 기본 키로 동작합니다. 바꾼 키는 저장만 됩니다" 문구는 틀렸다.** `App::shortcuts` · `trackb_shortcuts` ·
  `track_c::windows` · `parity2_ui::shortcuts` 가 프레임마다 `settings.shortcuts` 를 읽어 `keys::pressed` 로 본다. 문구를 지우고
  "바꾼 키는 바로 적용됩니다"로 바꿨으며, 합성 입력 시험으로 확인한다(아래 4-5).
- **테마 목록의 '만나로 (밝음)'** 은 `theme::ThemeId` 에 따로 없고 '밝게'와 같은 색이었다. 고를 수 있는 목록에서 뺐다.
  설정에 `manna` 가 저장돼 있으면 실제로 쓰이는 '밝게'로 보여 준다(값은 건드리지 않는다).
- **설정 전체 되쓰기**: 전에는 창이 프레임마다 설정 전체를 복사해 두었다가 무엇이든 바뀌면 `*d = data` 로 통째로 되썼다.
  그 사이 다른 창(템플릿 편집 · 출력 설정 · 리모컨)이 바꾼 값이 옛 값으로 돌아갈 수 있었다. 지금은 바꾼 칸 하나만 쓴다
  (`settings_items::patch`). 화면용 사본에서도 템플릿 본문 · 송출 기록 같은 큰 칸은 뺀다.
- **단축키 충돌 판정**이 공백 · 대소문자만 맞췄다. 지금은 `Ctrl`/`Control`/`Cmd`, 꾸밈 키 차례, `pgdn` 같은 줄임말을 같은 키로 보고,
  알 수 없는 키는 "이 단축키는 듣지 않습니다"로 알린다. 저장할 때는 프로그램이 읽는 한 가지 모양(`Ctrl+Shift+F`)으로 고쳐 쓴다.

## 2. 사용성 기준 (docs/ux-rules.md 에 비춘 점검)

| 기준 | 적용 |
|---|---|
| 상태를 보여 준다 | 윗줄 오른쪽에 "✓ 적용됨 · 자동 저장: 항목 이름", 오류는 빨간 글. 창 열기 줄마다 지금 상태 한 줄 |
| 사용자 말로 | 설정 키 이름 대신 설명 한 줄. 포트 · 주소 같은 것은 '고급 설정'에 접어 둠 |
| 되돌릴 수 있게 | 윗줄 '되돌리기'(방금 바꾼 것 또는 방금 한 기본값 복원 묶음), 항목별 '기본값으로', 분류별 '이 분류를 기본값으로…' |
| 실수를 막는다 | 분류 복원 · 모든 단축키 복원은 무엇이 바뀌는지 보여 주고 한 번 더 묻는다. 글자 크기는 범위 막대(70~200%), 틀린 키는 저장하지 않음 |
| 기억하게 하지 말고 보이게 | 모든 값 항목에 "지금: … · 기본값: …". 단축키 표에 기본값 열 |
| 필요한 것만 | 9분류로 나누고, 검색하면 결과만. 고급 항목은 접기(검색으로 오면 펼침) |
| 오류는 알아듣게 | "'Hyper+Q' 은 알 수 없는 키라 저장하지 않았습니다. 예: F6, Ctrl+K, PageDown" |
| 도움말 | 항목 이름에 마우스를 올리면 설명, 단추마다 툴팁 |

### 기본값 복원이 건드리는 범위

`settings_items::ITEMS` 에서 `reset: true` 인 값만 돌린다 — 켜기/끄기 · 고르기 · 막대 · 숫자 · 예약 키 글.
다음은 **어떤 복원으로도 바뀌지 않는다**(시험 `기본값_복원은_비밀_주소_파일_언어를_건드리지_않는다` 가 목록을 지킨다):
템플릿과 출력별 템플릿 선택, 로고 화면 그림, 언어, 로컬 서버 포트, OBS · 리모컨 · 내부망 · AI 의 주소 · 비밀번호 · PIN · 키,
스트림덱 보안 키, 동기화 폴더, 장비 · Companion · 카메라, 큐시트 · 성경 자료, 설정 파일에 있는 모르는 칸.
'설정 전부 초기화' 단추는 만들지 않았다.

## 3. 쓰는 법 (점검할 때)

- 여는 곳: 파일 → 설정, `Ctrl+,`, 머리 줄 톱니.
- 점검 인자: `--settings-cat send|output|obs|ui|keys|data|backup|remote|about` (그 분류로 열기), `--settings-q "찾을 글"` (검색한 채 열기).
  `--win 1280x800 --shot 파일.png` 와 함께 쓰면 그 화면을 찍고 끝난다.
- 주의: `--data <빈 폴더>` 로 처음 켜면 기존 워십프리젠터 자료를 그 폴더로 **복사**해 오면서 미리 넣어 둔 settings.json 을 덮는다.
  점검용 설정(자동 업데이트 · 통계 · 리모컨 끄기)은 한 번 켠 뒤에 고쳐야 남는다. (이번 작업에서 실제로 겪었다 — 5절)

## 4. 동작 시험

`cargo test -p wp-app --offline settings_` — 단위 12개 + 합성 입력 8개.
합성 입력 시험은 실제 화면 전체(`App::ui_body`)를 headless 로 그리고, 그려진 위젯 자리에 포인터 · 글자 · 글쇠 사건을 넣는다.
보이지 않는 항목은 마우스 휠로 스크롤해서 누른다(코어 값을 직접 바꿔 통과시키지 않는다).

| # | 시험 | 확인하는 것 |
|---|---|---|
| 4-1 | `검색해서_결과를_누르면_그_항목으로_간다` | '글자 크기' → 조작 화면의 그 항목(강조 · 조절 칸 보임), '37528' → 접힌 고급 항목이 펼쳐져 보임, 'F6' → 단축키 쪽의 그 줄만, 없는 낱말 → 결과 없음 |
| 4-2 | `바꾸면_그_칸만_코어에_쓰이고_되돌리기는_그_칸만_돌린다` | 창이 열린 뒤 다른 곳에서 템플릿 이름 · navMode · 비밀 · 모르는 칸을 바꿔 두고 체크 칸을 눌러도 그 한 칸만 바뀜. 고르기 칸, 되돌리기, 항목별 기본값으로 |
| 4-3 | `분류_기본값_복원은_묻고_그_분류만_돌리며_되돌릴_수_있다` | 그만두기 = 변화 없음, 돌리기 = 그 분류 값만(다른 분류 · 비밀 · 주소 · 파일 · 템플릿 · 단축키 · 큐시트 그대로), 되돌리기 = 복원 전 그대로 |
| 4-4 | `로고_화면_그림은_파일을_고르고_지운다` | 파일을 고르면 가져온 주소가 설정에 들어가고, 지우기는 설정만 비우고 파일은 둔다 |
| 4-5 | `바꾼_단축키가_바로_듣고_틀린_키는_저장되지_않는다` | 키 칸에 `Hyper+Q` → 저장 안 됨 · 까닭 표시. `f8` → `F8` 로 저장. 설정을 닫고 F9(송출) → **F8 이 다음 슬라이드, F6 은 더는 안 들음**. 같은 키 → 충돌 요약. 하나만 기본값 → F6 이 다시 들음 |
| 4-6 | `모든_단축키_기본값은_묻고_바꾼_키만_돌리며_되돌릴_수_있다` | 확인 · 그만두기 · 되돌리기, 모르는 동작 · 전역 단축키 · 예약 키는 그대로 |
| 4-7 | `센터의_열기_단추가_실제_창을_연다` | 열기 단추 18개(출력 설정 · 템플릿 · 테마 · OBS 원격 · 내부망×2 · 작업공간 · 번역본 · 주석 · 동기화 · 큐시트 관리 · 사용 기록 · 리모컨 · 스트림덱 · 장비 · 카메라 · 업데이트 · 정보)가 그 창의 열림 상태를 켠다. 주소 복사, OBS '슬라이드 그대로' |
| 4-8 | `화면_1280x800_에서도_창과_분류가_화면_안에_든다` | 9분류 모두에서 창이 화면 안(너비 900 이상), 분류 줄과 항목 · 조절 칸이 창 너비 안 |
