## 7. '새 버전' 받기 → 설치 끝까지 (`update-e2e.ps1`)

찾은 위험: 조작 화면의 설치는 `Setup /S --updated --force-run` 을 `/D=` 없이 실행해, 설치 파일이 **등록된 설치 자리**에 깐다.
임시로 풀어 둔 사본에서 설치를 누르면 실제 설치본이 바뀌고, `--force-run` 은 인자 없이 켜서 실제 자료를 연다 — 그래서 지난번에는 '찾음'까지만 봤다.
점검용 환경 변수를 더함(사용자는 쓸 일 없음): `WP_UPDATE_AS_VERSION`(옛 판인 척), `WP_UPDATE_TEST_DIR`(`/TEST /D=<폴더>` 를 붙이고 `--force-run` 뺌),
`WP_UPDATE_E2E=1`(켜자마자 확인 → 받기 → 설치 실행 → 끔, 조작 화면 단추와 같은 함수).

2026-11-28 결과: 공개 2.1.1 설치 파일로 임시 폴더에 `/S /TEST` 설치 → 그 실행 파일을 이 가지 판으로 바꿔 '2.1.0' 으로 켬 →
2.1.1 찾음 → 받기 · SHA-256 검증 'ready' → 설치 실행(`/S --updated /TEST /D=…`) → 끔 → 임시 폴더의 실행 파일이 공개 2.1.1 과 해시가 같아짐 →
`--data` 임시 자료로 켜짐(캡처). 실제 설치본 실행 파일 해시(2735…0E87) · 레지스트리 설치 자리 · 제거 항목 판(2.1.1)이 전후 그대로.
남은 것: `--force-run` 다시 켜기는 실제 자료를 열므로 점검에서 뺐다(설치 파일의 `Exec` 한 줄 — 2.1.0 → 2.1.1 실제 사용자 갱신으로 이미 쓰임).
