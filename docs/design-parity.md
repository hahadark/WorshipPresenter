# 조작 화면 디자인 동등화 (Electron 판과 똑같이)

사용자 지시(2026-11-14): "디자인도 완전 똑같이 해줘". Rust(egui) 조작 화면을 Electron 판 조작 화면과 같은 모양으로 맞춘다.

## 기준

- 기준 화면(git 에 넣지 않음, 성경 본문 저작권·교회 자료 포함): `tmp/design-ref/`
  - `01-start.png` 시작 화면(큐시트·본문·LIVE·빠른 설정·아래 송출 줄)
  - `02-search-live.png` 장절 검색 결과 + LIVE
  - `03-cue-editor.png` 순서 편집칸(본문 패널 위쪽 카드)
  - `04-library.png` 라이브러리 탭(아이콘 탭 줄)
  - `rust-before.png` 바꾸기 전 Rust 화면
  - 기준 화면 크기: CSS 1600×960, 배율 1.5 (그림 2400×1440)
- 살아 있는 기준: Electron 판을 복사 자료로 띄워 두었다면 브라우저로 `http://127.0.0.1:37528/control/` 를 열어 더 찍을 수 있다(포트는 바뀔 수 있음, netstat 으로 확인). 원본 자료(`%APPDATA%\WorshipCue\data`)로는 띄우지 않는다.
- CSS 원본: `F:\aside\WorshipCue\src\web\control\control.css` (1474줄). 색은 `:root` 변수가 기준이다.
- 화면 구조: `F:\aside\WorshipCue\src\web\control\index.html`, 각 패널 js.

## 글꼴

- Electron 조작 화면 글꼴은 Pretendard(OFL). 굵기별 고정 글꼴을 `assets/fonts/Pretendard-{Regular,Medium,SemiBold,Bold}.ttf` 로 만들어 두었다(PretendardVariable.woff2 에서 변환). 라이선스 `assets/fonts/OFL-Pretendard.txt`.
- 기본 글자 크기 14px, 줄 높이 1.45. 맑은 고딕은 빠진 글자 대체용으로만.

## 아이콘

- Electron 은 Lucide 선 아이콘 한 벌(`web/shared/icons.js`, Rust 저장소에도 같은 파일)을 쓴다. 이모지를 쓰지 않는다.
- egui 에서는 SVG 를 그림으로 그려 글자색으로 물들인다(egui_extras svg 로더).

## 화면 구성 (기준 화면에서 읽은 것)

- 맨 위 메뉴 줄(menubar 색): 파일·큐시트·송출·보기·도구·도움말
- 머리 줄: 로고 아이콘 + "워십프리젠터" · 넓은 검색칸(돋보기 아이콘, 둥근 테두리, 포커스 때 accent 테두리) · 검색 방식(자동) · 번역본 · 병행 번역 · 노란 '미리보기 끔 · 바로 송출' 토글 · 작업공간 고르기(배치 아이콘) · 설정(톱니)
- 패널 탭 머리: 제목 + ✕, 오른쪽에 ▾·독립 창 아이콘. 활성 탭 아래 accent 밑줄
- 큐시트 패널: '큐시트 (예배 순서) | 성경 책' 분할 단추, 큐시트 고르기 + 폴더 단추, 순서 줄(번호 · 종류별 색 네모 아이콘 · 굵은 제목 · 흐린 둘째 줄), 고른 줄은 sel 바탕 + 왼쪽 pv 띠 + 연필 단추, 아래 넣기 단추 격자(찬송가·PPT·성경·찬양·가사·공지·제목·더보기), 도움말 글
- 본문 패널: '본문 | 주석' 분할 단추 · '편집칸' 단추 · 제목(굵게) + 흐린 부가 글 · '목록 | 격자 | 전체 격자 | 전체 목록' 분할 단추. 절 목록은 hl 색 절 번호 + 큰 글자, 미리보기 중인 범위는 왼쪽 pv 띠
- 편집칸 카드: 종류 아이콘 + "7번 성경" · ▲ ▼ · 파란 '슬라이드 편집' · 복제 · 지우기 · ✕, 아래 이름표-입력칸 2단 격자
- LIVE 패널: 빨간 LIVE 배지 + 제목 · '예배당 | OBS' 분할 단추 · 빨간 테두리 화면 · "1 / 3 · 다음: …" 줄 · '그리기' 단추 · '지금 화면' 칩 · 슬라이드 칩(1. 3:16 …, LIVE 칸은 빨간 테두리)
- 빠른 설정: '빠른 설정' 이름표 + 대상 분할 단추 · 템플릿 · 테마 · 분할 · 이동 · 자세히 ▸ · 접기 ▾, 아래 글꼴·글자 크기(− 막대 + px)·본문 색 동그라미·위치 3×3 격자
- 라이브러리: 아이콘 탭 줄(찬양·찬송가·PPT·이미지·영상·카메라·음악·오버레이·템플릿)
- 아래 송출 줄: 이전 F5 · 다음 F6 · 빨간 송출 F9 · 글자 숨김 F10 · 지우기 ▾ · 모두 지우기(빨간 테두리) · 즉석 자막 Ctrl+T · 보조 화면 꺼짐 Ctrl+Shift+F, 단축키는 작은 kbd 칩. 오른쪽에 출력 연결 상태 점(예배당 화면·OBS 전체·OBS 자막)

## 진행 방식

1단계(기반): 테마·글꼴·아이콘·공용 위젯(분할 단추·배지·아이콘 단추·kbd 칩·패널 탭 머리) + 비교용 점검 인자(창 크기 고정). 2단계(병렬): 머리 줄·송출 줄 / 큐시트 패널 / 본문·편집칸·빠른 설정 / LIVE·미리보기·라이브러리. 단계마다 같은 크기로 찍어 기준 화면과 나란히 비교한다.
