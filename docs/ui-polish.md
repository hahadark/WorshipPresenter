## 가장 큰 문제 5개 (두 모델 겹침 + 내 판단)

1. **창 안 설정 양식이 인스펙터와 다름** — 설정 창 · 출력 설정 · 도구 창이 '굵은 이름 → 조절 칸 → 긴 설명 → 지금: …(기본값)' 을 세로로 쌓아 웹 문서처럼 보임 (pro_tool · consistency, 두 모델 모두 최다).
2. **창 테두리가 들쭉날쭉** — 어떤 창은 제목 왼쪽에 접기 삼각형 ▼, 어떤 창은 없음. 라이브러리 · 출력 설정 창이 화면 아래로 넘쳐 잘림, 얇은 스크롤 막대가 거의 안 보여 '잘렸다' 로 읽힘.
3. **영어 화면의 이름 섞임** — 같은 출력을 'Main' · 'Main screen' · 'Sanctuary screen' 으로, 화면 구성을 'Scenes'(OBS 장면과 같은 말)로 부름. '오픈라우터' · '한 절씩' 같은 글이 번역 안 됨.
4. **같은 무게의 단추 줄** — 회중 메시지 · 무대 화면 · 즉석 자막 · 출력 설정 · 큐시트 관리에서 실제로 화면에 내보내는 단추가 보조 단추와 똑같이 보임.
5. **뜻 없는 색 · AI 장식** — 연결 점검의 보라 체크 · 하늘 i, AI 단추의 반짝이(마술봉) 아이콘, 일부 둥근 상자 카드(추가 출력 · 테마 카드).

## 안 고친 채 남은 것 · 제안

- **입력칸 초점 테두리 · 체크 표시 색**: egui 기본 선택색(`selection.stroke`)이 전문가 테마에서 흰색인데, 체크 · 라디오 · 고른 글이 어떤 곳에서는 푸르스름하게 보인다는 지적(Gemini). 송출 화면과 상관없는 곳이라 이번에는 두었다 — 다음에 `theme::style` 의 `selection` · `hyperlink_color` 를 노랑/회색 규칙에 맞게.
- **좁은 창(1280 미만) · 배율 150% 에서 인스펙터가 접혀 있다는 표시**: 막대 오른쪽 끝 단추만 있다. 접힌 판 가장자리에 얇은 손잡이를 두는 안 (자리 옮김이라 제안만).
- **송출 중 뷰어 안 '예배당 화면 꺼짐' 띠 + 아래 알림 띠 중복**: 하나로 합치는 안 (주인이 2.0.8 에서 고른 자리라 제안만).
- **긴 메뉴 이름**(`웹 편집기 (다른 컴퓨터에서 큐시트 고치기)`, `말로 시키기 (찾기칸에 '>' 로도)`): 괄호 설명을 메뉴 오른쪽 흐린 글로 옮기는 안.
- **밝게 · 고대비 테마**를 전문가 규칙(빨강 = 송출 중 · 노랑 = 다음 · 흰 송출 단추)에 맞춘 '전문가 밝게' 를 따로 두는 안 (design-pro-apply.md 제안과 같음).
- 아직 옛 모양 그대로인 창: 템플릿 편집 · 출력 테마 관리(썸네일 카드 — 갤러리라 둠), 큐시트 관리 왼쪽 필터 칩, 음성 인식 모델 고르기 단추.
