# 인터페이스 다듬기 (2026-11-27, sources 가지 위)

목표: 2.0.8 의 (나) 어두운 전문가용 디자인 위에 여러 작업자가 더한 창·구획을 **한 사람이 만든 한 도구처럼** 맞춘다. 기능 · 단축키 · 조작 자리는 바꾸지 않는다. 송출 결과(웹 출력 · 미리보기 그림)는 건드리지 않는다.

## 어떻게 했나

1. **전부 찍기** — `tools/polish/shots.js` (경우마다 시험 자료를 새로 복사, `WP_LEGACY_DATA` = 빈 폴더). 시험 자료는 `○○교회` 가상 큐시트 2개 · 개역한글만 · 개인 경로/주소 지움. 95장: 주 화면(1000×640 · 1600×960 · 1920×1080 · 배율 125%·150% · 밝게 · 고대비 · 영어 · 빈 상태 · 알림 띠 · 성경 · 라이브러리), 인스펙터 탭 4, 메뉴 6, 창 45(+ 도구 창 6), 설정 9분류, 영어 7, 밝게·고대비 6, 좁은 창 2. `tmp\polish\before\`.
   - 점검 인자로 못 열던 도구 창(리모컨 · 외부 단추 · 장비 · 내부망 · 휴대폰 카메라 · 웹 편집기)은 `--open-menu d:remote` 로는 안 열려서 `--tool <이름>` 으로 찍었다.
   - 붙여 넣기 창(`--open-a2 paste`)은 이 PC 클립보드 글이 보여서 외부로 보내지 않았다.
2. **외부 판단** — `tools/polish/judge.py` (OpenRouter, 키는 환경변수만). 그림 보는 모델 두 개(Claude 계열 아님): **google/gemini-3.8-flash** · **openai/gpt-5.6-luna**. 8장씩 묶어 기준 7개(`tools/polish/rubric.md`) 점수 1~10 + 지적 JSON. `tools/polish/score.py` 로 평균.

## 가장 큰 문제 5개 (두 모델 겹침 + 내 판단)

1. **창 안 설정 양식이 인스펙터와 다름** — 설정 창 · 출력 설정 · 도구 창이 '굵은 이름 → 조절 칸 → 긴 설명 → 지금: …(기본값)' 을 세로로 쌓아 웹 문서처럼 보임 (pro_tool · consistency, 두 모델 모두 최다).
2. **창 테두리가 들쭉날쭉** — 어떤 창은 제목 왼쪽에 접기 삼각형 ▼, 어떤 창은 없음. 라이브러리 · 출력 설정 창이 화면 아래로 넘쳐 잘림, 얇은 스크롤 막대가 거의 안 보여 '잘렸다' 로 읽힘.
3. **영어 화면의 이름 섞임** — 같은 출력을 'Main' · 'Main screen' · 'Sanctuary screen' 으로, 화면 구성을 'Scenes'(OBS 장면과 같은 말)로 부름. '오픈라우터' · '한 절씩' 같은 글이 번역 안 됨.
4. **같은 무게의 단추 줄** — 회중 메시지 · 무대 화면 · 즉석 자막 · 출력 설정 · 큐시트 관리에서 실제로 화면에 내보내는 단추가 보조 단추와 똑같이 보임.
5. **뜻 없는 색 · AI 장식** — 연결 점검의 보라 체크 · 하늘 i, AI 단추의 반짝이(마술봉) 아이콘, 일부 둥근 상자 카드(추가 출력 · 테마 카드).
