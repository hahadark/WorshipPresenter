# 2차 시안 — 맥 프로그램 느낌 (코드 수정 없음, 시안만)

1차(A·B·C)는 셋 다 "어두운 바탕 + 세 칸 대시보드 + 깔끔한 고딕" 뼈대에 색·모서리만 바꾼 것이라 다시 AI 티가 났다.
2차는 **뼈대부터** 맥 프로그램식으로 다시 짰다: 통합 제목 줄 겸 도구 막대 · 왼쪽 원본 목록(사이드바)과 묶음 제목 · 오른쪽 인스펙터(접는 구획 · 오른쪽 맞춤 '이름:' 양식) · 구획 나눔 단추 · 팝업 단추 · 얇은 구분선 · 강조색 하나 · 아이콘은 도구 막대에만 단색.
카드 · 칩 · 알약 꼬리표 · 종류별 색 아이콘은 하나도 쓰지 않았다.

모든 시안은 1차와 같은 예배 순서와 같은 상태다: **6 성경봉독 송출 중(요 15:2, 2/8절, 00:42 째)**, **7 설교 다음**, 1~5 지나감. PNG 는 모두 2400×1440.

## 추천: **(나) 어두운 전문가용 맥**

1. **예배 중 방송실에 맞는다.** 중간 회색이라 새까만 1차보다 눈이 덜 피곤하고 밝은 (가)·(다)보다 눈부심이 없다. 빨강 = 송출 중, 노랑 테두리 = 다음 이 표 · 뷰어 · 시간표 세 곳에서 같고, 송출 단추는 어두운 막대 위 단 하나의 흰 단추라 가장 먼저 보인다. 지우기·숨김은 아이콘 도구라 실수로 누르기 어렵다.
2. **AI 티가 나는 뼈대를 실제로 바꾼다.** 카드 셋이 아니라 '컨트롤 막대 + 브라우저 + 뷰어 + 인스펙터 + 타임라인'이라는 영상·음악 편집 프로그램의 뼈대이고, 예배 시간표는 이 프로그램만의 얼굴이 된다(다른 교회 송출 프로그램에서 보기 드문 화면).
3. **맥·Windows 둘 다 자연스럽다.** 전문 프로그램은 Windows 에서도 이런 모양이 흔해(DaVinci Resolve 등) Windows 판이 어색하지 않다 (`windows-vs-mac.png`).

순서 제안: ① 토큰 정리 → ② (나) 팔레트·컨트롤 막대·인스펙터 양식 (배치는 그대로 두고 먼저 써 보기) → ③ 큐시트 브라우저·두 뷰어 배치 → ④ 시간표(보기 전용). (가) 는 (나) 의 '밝게' 짝으로 같은 배치에 팔레트만 바꿔 얹을 수 있다 — 낮 예배·연습용.
