> 코드는 고치지 않았다. 시안 HTML·PNG만 있다. 나란히 보기는 `compare.html`.
> 모든 PNG 는 2400×1440 (창 1600×960 × 화면 배율 1.5) — `current.png` 와 같은 크기.
> 다시 찍기: `sh shot.sh a-main` (조작 화면) · `sh shot.sh a-dialog 900 640` (창). 크롬 headless 를 쓴다.

| 파일 | 내용 |
|---|---|
| `current.png` | 설치본 2.0.7 을 **임시 자료 폴더**(`--data`)로 띄워 찍은 지금 화면 (`--win 1600x960 --import-cue … --item 6 --send --shot`). 주인 자료는 1.x 자료를 읽어 복사만 했고 바꾸지 않았다. 설정을 복사해 와서 '바로 송출' 모드·주인 템플릿으로 찍혔다 |

## 1. 진단 — 무엇이 'AI가 만든 것 같은' 인상을 주나

코드(`crates/wp-app/src/theme.rs` · `widgets.rs` · `cue_ui.rs`)와 `current.png` 에서 실제로 확인한 것만.

1. **순서 종류 색이 Tailwind 기본 팔레트 그대로.** `theme.rs type_color` 의 15색이 `#2563eb`(blue-600) · `#4f46e5`(indigo-600) · `#7c3aed`(violet-600) · `#0891b2`(cyan-600) · `#d97706`(amber-600) · `#0f766e`(teal-700) · `#db2777`(pink-600) … 이다. 이걸 **연한 색 칩 안의 Lucide 선 아이콘**(큐시트 모든 줄 · 순서 넣기 단추 · 라이브러리 탭)으로 쓴다. 'Tailwind 색 + 둥근 칩 속 Lucide 아이콘'이 요즘 생성형 UI 의 가장 흔한 모양이라, 처음 보는 사람 눈에 이게 가장 먼저 걸린다. 게다가 색이 15개라 뜻이 외워지지 않는다(성경 파랑 · 찬송가 남색 · 찬양 보라 구분이 안 됨).
2. **푸른 기 도는 슬레이트 회색 판 + 파랑 강조.** 바탕 `#121519` · 판 `#1a1e25` · `#222731` · 강조 `#4f8cff`. 흔한 '다크 모드 SaaS' 조합 그대로다. 테마 5개(어둡게·밝게·고대비·따뜻하게·푸른 밤)도 같은 구조에 색 값만 바꾼 것이라 성격이 생기지 않는다.
3. **모든 조작이 같은 무게의 '테두리 둥근 상자'.** 위 줄에 상자 9개, 아래 송출 줄에 상자 9개, 단축키(F5·F9…)도 작은 상자, 탭도 분절 상자. 모양만으로는 무엇이 중요한지(송출) · 무엇이 가끔 쓰는 것인지(복제·즉석 자막) 알 수 없다. 둥글기도 1·2·3·4·5·6·8·10·12 아홉 가지가 섞여 있다 (`CornerRadius::same(4)` 25번 · `(6)` 14번 · `RADIUS` 13번 · `(8)` 10번 · `(5)` 7번 …) — 규칙이 없는 '대충 다 둥글게'.
4. **글자 위계가 거의 없다.** `font(…)` 직접 호출의 대부분이 12px·14px 두 크기이고, `Weight::Regular` 138번 · `SemiBold` 40 · `Bold` 33. 그래서 편집칸의 '7. 설교' 제목이 그 옆 '슬라이드 편집' 단추 글자와 같은 크기다. 화면에서 가장 큰 글씨가 검색칸 안내문이다.
5. **상태색이 서로 싸운다.** 한 화면에 노랑(바로 송출 띠 · 예배당 꺼짐 경고 두 군데), 빨강(LIVE 테두리 · 고른 순서 채움 · 송출 단추 · 순서 삭제 · 모두 지우기 테두리), 초록(편집 중인 슬라이드 강조), 파랑(슬라이드 편집 · 분절 탭 · 검색칸 테두리)이 동시에 있다. **빨강이 '송출 중' · '고른 것' · '지우기(위험)'를 함께 뜻한다** — 어두운 방송실에서 가장 헷갈리면 안 되는 색이 여러 뜻이다. '다음에 나갈 것'을 뜻하는 고유한 색은 없다.
6. **뜻 없는 카드 반복.** 독 패널이 모두 같은 카드(둥글기 12, 사이 틈) + 같은 머리(제목 · ✕ · ▾ · ⧉)이고, 큐시트 카드 안에 다시 '큐시트(예배 순서) | 성경 책' 분절 탭이 있어 머리가 두 줄이다. 아래 '순서 넣기' 단추 6개도 같은 상자 격자.

요약: **개별 요소는 깔끔하지만, 색·모양·크기가 모두 '기본값'이라 무엇을 위한 도구인지가 화면에 드러나지 않는다.** 예배 송출 도구만의 사정(지금 나가는 것 / 다음 것 / 잘못 누르면 큰일 나는 것)이 디자인 규칙에 들어가 있지 않다.

세 방향 모두 공통으로 하는 것: 종류 색 15개 → 없애거나 3개 이하, 빨강은 '송출 중' 하나만, '다음(미리보기)'에 고유한 색, 송출 단추는 화면에서 가장 무겁게, 위험한 단추(지우기·삭제)는 채우지 않음, 제목 글자는 단추 글자보다 확실히 크게. 그리고 모두 egui 로 그대로 그릴 수 있는 것만 썼다(평평한 채움 · 선 · 둥근 사각형 · 점선 · 두 겹 사각형. 흐림·그라데이션·여러 겹 그림자 없음).

## 2. 세 방향

### A · 방송 콘솔 — "방송실 스위처처럼: 평평하고 빽빽하게, 상태는 탈리 색으로만 말한다"

방송 스위처(ATEM 등)의 탈리 규칙 — **빨강 = 지금 나감(PGM), 초록 = 다음(PVW)** — 을 화면 전체의 유일한 색 규칙으로 쓴다. 교회 방송 봉사자에게 이미 익숙한 약속이다.

- **색**: 바탕 `#0f0f0e` · 판 `#151514` · 올린 면 `#1d1d1b` · 꺼진 면 `#0a0a09` · 선 `#2b2a27`/`#3d3b37` · 글 `#e9e6de`/`#c9c5ba` · 흐린 글 `#8e8a7f`/`#66635b` (푸른 기 없는 따뜻한 먹색). 송출 `#e2342c`(바탕 `#3a1413`) · 다음 `#2ea84f`(바탕 `#11301b`) · 키보드 초점·고른 것 `#f2a900`. **파랑 없음, 종류 색 없음**(종류는 '성경·찬양·공지' 글자로 한 열).
- **글꼴**: IBM Plex Sans KR (OFL, 400·500·600·700) + 숫자·시각·단축키는 IBM Plex Mono (OFL). 한글이 섞인 이름표는 Plex Sans KR.
- **모서리·선·간격**: 판 0, 단추·입력칸 2px (둘만). 패널 사이 틈·카드 없음 — 1px 선으로만 나눔. 4px 격자, 목록 줄 42px, 줄마다 아래 선.
- **단추**: 사각 평면 + 1px 선. 분절 단추는 붙여 쓰고 고른 것은 흰 채움(반전). **아래 송출 줄은 하드웨어 키처럼**: 높이 64px 키, 왼쪽 위에 키 이름(F5·F9 TAKE), 아래에 동작. 송출(TAKE) 키만 빨강 채움이고 다음 나갈 이름을 쓴다("송출 ▶ 7 설교"). 지우기류는 채움 없는 키.
- **목록**: 표 — `# | 시각 | 순서(+부제) | 종류 | 분`. 왼쪽 4px 탈리 띠: 빨강 = 송출 중, 초록 = 다음. 지나간 순서는 45% 흐리게.
- LIVE 아래에 '다음 순서 · F9 로 송출' 칸과 출력 상태표(예배당 · OBS 성경 · OBS 찬송가 · 무대)를 글자로.

### B · 주보 — "교회 주보·순서지를 펼쳐 놓은 듯: 순서는 글로 읽히고, 꾸밈은 괘선과 글꼴로만"

큐시트를 **주보의 예배 순서**처럼 보이게 한다: 가운데 정렬 표제("주일 성결예배"), 시각 · 순서 이름(명조) · 점선 지시선 · 맡은 이/본문. 단추는 대부분 밑줄 글(링크)로 낮추고 송출만 채운다.

- **색**: 바탕 `#1a1814` · 판 `#201d18` · 올린 면 `#2a2620` · 꺼진 면 `#14120f` · 선 `#383228`/`#544b3d` · 글 `#efe7d6`(미색 종이) / `#d4cab4` · 흐린 글 `#a2977f`/`#776d5a`. 송출 진홍 `#d0453a` · 다음 금색 `#c9a24a`(바탕 `#2c2416`). 초록은 '켜짐' 상태 글자(`#8fcf9e`)에만.
- **글꼴**: 순서 이름 · 패널 제목 · 표제 · 숫자 큰 글씨 = **Noto Serif KR**(OFL, 600·700) / 나머지 조작 글 = 지금의 **Pretendard** 그대로.
- **모서리·선·간격**: 판 0, 단추 3px. 위·아래 줄 경계는 3px 두 줄 괘선(주보 머리), 패널 사이는 1px 세로 괘선, 목록은 점선 지시선. 여백을 넉넉히(패널 안쪽 16~20px, 목록 줄 49px).
- **단추**: 세 등급만 — ① 송출: 진홍 채움 ② 고르는 것(보낼 곳 · 분 · 고정): 1px 선 상자, 고른 것은 밝은 선 + 굵게 ③ 나머지(복제 · 열기 · 테마 고치기 · 삭제): 밑줄 글. 탭은 글 + 밑줄 2px.
- **목록**: 왼쪽 3px 띠 + 연한 바탕 — 진홍 = 송출 중, 금색 = 다음. 이름 옆 작은 꼬리표('송출 중' · '다음'). 종류 아이콘·색 없음.
- 덤: 표제 색(금색)을 교회력 색(대림절 보라 · 사순절 자주 · 성령강림 빨강)으로 바꾸는 선택을 넣으면 '이 프로그램만의' 성격이 더 생긴다 (시안에는 안 넣음).

### C · 지금·다음 — "처음 온 봉사자도 바로: 지금 나가는 것과 다음 것이 가장 크게, 누르는 것은 손가락 크기로"

- **모서리·선·간격**: 둥글기 세 가지만 — 단추·칸 10px, 카드 14px, 알약(검색 · 토글 · 꼬리표) 끝까지. 선은 거의 안 쓰고 면의 밝기로 나눔. 10px 간격, 목록 줄 50px, 단추 높이 36~48px.

## 3. 적용에 드는 일

## 4. 추천: **A · 방송 콘솔**

1. **'AI 같은 인상'의 뿌리를 가장 직접 걷어낸다.** Tailwind 종류 색 · 틴트 칩 아이콘 · 파랑 강조 · 둥근 상자 · 카드 틈이 모두 사라지고, 남는 색은 '송출 중 빨강 / 다음 초록' 두 개뿐이다. 무엇을 하는 도구인지가 화면에서 바로 읽힌다.
2. **예배 중 방송실 조건에 가장 맞다.** 가장 어두운 바탕(눈부심 적음), 송출/다음 구분이 방송 장비와 같은 약속, 송출 키 하나만 채워져 있고 지우기류는 채움이 없어 잘못 누르기 어렵다. 빽빽해서 좁은 노트북 화면에서도 지금 배치가 그대로 들어간다.
3. **일이 가장 작고 되돌리기 쉽다.** 배치를 바꾸지 않고 `theme.rs` · `widgets.rs` · `cue_ui.rs` 중심으로 2~3일, 새 테마로 추가하면 기존 5개 테마도 남는다.

B 의 좋은 점(주보 같은 큐시트 머리 · 순서 이름에 명조)은 A 위에 나중에 '큐시트 표제만 명조'로 얹을 수 있고, C 의 아래 줄 '지금/다음 카드'도 A 의 송출 키 옆에 붙일 수 있다 — 먼저 A 로 바탕 규칙을 정하고, 써 보신 뒤 하나씩 더하는 순서를 권한다.
