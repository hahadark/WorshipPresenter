# 패널 기능 동등성 점검 (2026-11-13)

## 원칙과 범위

- 사용자 지시에 따라 챗GPT 구독만 사용한다. 다른 모델·별도 유료 API로 전환하지 않는다.
- 릴리스·설치 파일·GitHub 업로드는 계속 정지한다.
- Electron 원본과 실제 사용자 자료는 수정하지 않는다. 실행 시험은 별도 데이터만 쓴다.
- 8개 패널을 배치할 수 있다는 사실만으로 패널 내용까지 동등하다고 판정하지 않는다.
- 컴퓨터 화면 제어 도구의 키 입력이 중단되어 해당 직접 조작은 검증 실패가 아니라 **미검증**으로 기록한다. 같은 도구 경로를 반복하지 않고 앱 내부 합성 입력 테스트로 전환한다.

## 독립 검토에서 확인한 차이

### 본문 패널 편집 접근

원본 `src/web/control/index.html`의 `panelMain`에는 본문/주석과 `cueEditor`가 함께 있다. Rust는 편집기가 큐시트 패널 안에만 있어 그 패널을 숨기거나 다른 탭을 선택하면 편집할 수 없었다. 본문 패널에서도 편집할 수 있게 하고 F2·Ctrl+Shift+E와 우클릭 편집 진입이 실제로 패널을 열도록 보완한다.

### 미리보기 템플릿

원본 `control.js`는 미리보기와 LIVE 각각의 순서별 템플릿을 적용한다. Rust는 LIVE 기준 `template_for` 결과를 양쪽에 넘겨 다음 순서의 모양을 잘못 보여 줄 수 있었다. 덱별 템플릿 계산과 각 패널의 예배당/OBS 보기를 분리한다. 실제 LIVE 출력 계약은 유지한다.

### 빠른 설정·라이브러리

원본 Quick의 대상은 예배당·OBS 성경·OBS 찬양이다. 출력 대상별 템플릿·분할·탐색·기본 디자인 조절을 기존 저장 경로와 연결한다. 원본 Library는 찬양·찬송가/PPT·그림/영상·카메라·음악·오버레이·템플릿으로 나뉜다. Rust의 찬양 전용 렌더를 이 전체 라이브러리와 같다고 볼 수 없다.

### 미디어 즉시 실행과 재생바

원본 `media.js`는 영상/음악 목록에서 큐시트를 바꾸지 않고 송출·재생하며, 정지·페이드·탐색·길이/남은 시간을 제공한다. Rust의 큐에 넣기·배경 지정만으로는 동등하지 않다. 기존 영상 상태와 음악 재생 계약을 재사용해 보완한다.

### 저장된 찬양 부를 순서

저장 순서의 선택·적용·삭제가 필요하다. 큐 항목의 `order`를 라이브러리에 저장할 때는 `songs::save`가 받는 `arrangement`로 변환해야 한다. 잘못된 키로 기본 순서를 지우는 회귀를 막는다.

## 먼저 통합한 메뉴 보완

- 큐시트 순서 우클릭의 예정 시간 편집은 관리 창과 같은 함수·범위·조건을 사용한다.
- PPT 나누기는 기존 PPT 도구 진입점을 연다. 메뉴 선택만으로 AI를 호출하지 않는다.
- 이 단계의 앱 테스트 10개가 통과했다.

최종 구현·실행 결과와 아직 검증하지 못한 범위는 `PARITY.md`의 최신 검증 절에 함께 기록한다. 이 문서 자체는 구현 완료의 증거가 아니다.
