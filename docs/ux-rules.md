# 조작 화면 사용성 규칙 (2026-11-14)

사용자 지적: "전반적으로 편의성이 떨어졌어. 썸네일에 마우스를 올리면 수정 아이콘이 떠야 하고, 테마 수정 인터페이스도 너무 후졌어. 인터넷이든 어디든 이런 인터페이스 설계 규칙을 찾아서 적용해."
이 문서는 조사한 공개 규칙과, 같은 종류의 예배 송출 프로그램이 쓰는 편집 화면 방식을 정리한 것이다. 화면을 만들거나 고칠 때 이 규칙으로 점검한다.

## 1. 일반 규칙 (출처)

### 닐슨의 사용성 10원칙 (Nielsen Norman Group, nngroup.com/articles/ten-usability-heuristics)
1. **시스템 상태를 보여 준다**: 누른 것·저장된 것·송출 중인 것을 바로 알 수 있게. 피드백은 가능한 한 즉시.
2. **사용자 말로 쓴다**: 'CSS 그라데이션', 'px', '주소' 같은 내부 용어 대신 '색 두 개로 번지게', '크기', '그림 고르기'.
3. **되돌릴 수 있게 한다**: 실행 취소·다시 실행, 분명한 취소·닫기, '원래대로'.
4. **일관성**: 같은 동작은 같은 아이콘·같은 자리. 원본 Electron 판과 같은 말·같은 배치.
5. **실수를 막는다**: 지우기 같은 되돌리기 어려운 동작은 확인하거나 되돌리기를 준다. 잘못된 값은 입력 단계에서 막는다(범위 있는 막대·고르기).
6. **기억하게 하지 말고 보이게 한다**: 숨은 단축키·오른쪽 클릭에만 기능을 두지 말고, 마우스를 올리면 그 자리에서 할 수 있는 동작이 보이게.
7. **익숙한 사람은 빠르게**: 단축키·두 번 누르기·끌어 놓기는 두되, 처음 쓰는 사람도 눈에 보이는 단추로 같은 일을 할 수 있게.
8. **필요한 것만 보이게**: 자주 쓰는 것은 앞에, 나머지는 '자세히'로 접는다(점진적 공개).
9. **오류는 알아듣게**: 무엇이 잘못됐고 어떻게 고치는지 쉬운 말로.
10. **도움말**: 단추에 마우스를 올리면 짧은 설명(툴팁).

### UX 법칙 (lawsofux.com, NN/g Fitts's Law)
- **피츠의 법칙**: 자주 누르는 대상은 크게, 손이 가는 곳 가까이. 아이콘만 있는 단추보다 아이콘+글이 찾기 쉽다.
- **힉의 법칙**: 선택지가 많을수록 고르는 데 오래 걸린다. 한 화면의 선택지를 줄이고 묶는다.
- **점진적 공개**: 기본 몇 개만 보이고 나머지는 펼치기.

## 2. 같은 분야 프로그램의 테마 편집 방식

- **ProPresenter 테마 편집기**(Renewed Vision 도움말): 가운데 **캔버스**(실제 화면 그대로), 오른쪽 **인스펙터**(고른 것에 따라 내용이 바뀜: 아무것도 안 고르면 화면 크기·배경, 글상자를 고르면 글꼴). 캔버스에서 직접 고르고 옮긴다.
- **EasyWorship 테마 편집기·인스펙터**(easyworship 도움말): 배경은 '없음·단색·그라데이션(두 색·방향·각도)·미디어' 중에서 고르고 색 고르기·투명도 막대로 정한다. 여백·세로 정렬·회전은 단추와 막대로. 테마는 끌어 놓아 순서에 적용.
- **Crater 테마 디자인**(getcrater.org 문서): 왼쪽 레이어, 가운데 캔버스(요 3장·찬송 가사 같은 견본 글로 실제처럼), 오른쪽 속성.

공통점: **실제 모양 그대로의 큰 미리보기 + 그 위에서 직접 조작 + 고른 대상에 맞춘 속성 칸 + 글로 된 값 대신 시각적 고르기(색 견본·막대·위치 격자·그림 고르기)**.

## 3. 이 프로그램에 적용할 규칙

### 썸네일·목록 (마우스 올림 동작)
- 썸네일(본문 패널 격자·전체 격자, 슬라이드 편집기 목록, 라이브러리 그림·영상)에 마우스를 올리면 모서리에 **아이콘 단추**가 뜬다: ✎ 편집, ＋ 뒤에 새 슬라이드, 건너뛰기/다시 보이기(눈 아이콘), 복제, ✕ 지우기 — 종류에 맞는 것만. 원본 grid.js 의 ✎/＋/✕ 와 같은 역할.
- 큐시트 순서 줄도 마우스를 올리면 연필(편집)·송출 단추가 보인다(고른 줄만이 아니라).
- 마우스 올림 때 바탕이 hover 색으로 바뀌고, 누를 수 있는 곳은 손 모양 커서.
- 아이콘 단추는 툴팁 필수. 단추 크기 24px 이상, 썸네일 모서리에 반투명 바탕.

### 테마(템플릿) 편집
- 3단: 왼쪽 템플릿 목록(**작은 그림 썸네일**과 이름, 지금 쓰는 출력 표시), 가운데 **큰 캔버스**(견본 성경·찬양·공지로 바꿔 보기, 실제 출력과 같은 그림), 오른쪽 **속성**(묶음별 접기: 배경 · 글자 · 위치와 여백 · 장절 · 로고 · 효과).
- 캔버스에서 직접 조작: 글 영역 테두리를 끌어 여백 조절, 로고를 끌어 위치, 장절 줄을 고르면 오른쪽 속성이 그 항목으로.
- 배경: '단색 · 그라데이션 · 그림 · 영상' 분할 단추. 그라데이션은 색 두 개와 방향(위→아래, 가운데 원형 등) 고르기로 만들고 CSS 글은 '고급'에만. 그림·영상은 파일 고르기 단추와 썸네일, 주소 글칸은 '고급'에만.
- 숫자는 막대+숫자칸 함께(범위 제한), 색은 견본 동그라미+고르기, 정렬은 아이콘 분할 단추, 위치는 3×3 격자.
- 바꾸면 바로 캔버스·미리보기·LIVE 에 반영되고 자동 저장, '저장됨' 표시. 실행 취소·'원래대로'(처음 연 상태로) 단추.
- '예배당에 쓰기 · OBS 자막에 쓰기 · OBS 찬송가에 쓰기'는 지금 어디에 쓰이는지 표시와 함께.
- 삭제는 확인.

### 그 밖
- 모든 아이콘 단추 툴팁. 비활성 단추는 왜 안 되는지 툴팁.
- 빈 상태에는 다음에 할 일을 알려 주는 글과 단추.
- 오래 걸리는 일은 진행 표시.
