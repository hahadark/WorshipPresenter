# 웹 화면 다시 짓기 — 휴대폰 리모컨 · 휴대폰 카메라 · 웹 편집기 (craft-web, 2026-11-28)

봉사자가 휴대폰 · 다른 컴퓨터의 브라우저로 여는 세 화면을 조작 화면(전문가 테마)과 한 벌로 다시 지었다.
예배당 · 방송 · 무대에 나가는 화면(web/output)은 건드리지 않았다.

## 공통 (web/shared/ui)

- `wpweb.css` — 토큰(`crates/wp-app/src/theme.rs build_pro` 와 같은 값) · 단추(`.btn` 도드라짐 · `.flat` · `.ghost` · 하나뿐인 흰 `.send`) · 입력칸 · 분절 단추 · 구획 머리 · 알림 · 아래에서 올라오는 판 · 켜고 끄기 · PIN 화면 · 불러오는 중 뼈대. 글꼴 Pretendard(이 PC 가 `/wpui/pretendard.woff2` 로 줌 — 바깥 주소 없음).
- `wpweb.js` — 한국어/영어(앱 설정 `uiLang` → 서버가 `<html data-app-lang>` 로 알려 줌, 없으면 브라우저 언어; 화면마다 `data-en` 으로 자기 영어를 가짐 — 큰 i18n-en.js 를 휴대폰에 내려보내지 않음), Lucide 아이콘 한 벌(조작 화면과 같은 것, ISC), 시간 제한 있는 요청, 누름 반응(눌림 → 성공 회색 점멸 / 실패 주황 흔들림 + 진동), 알림(되돌리기 단추 가능), 화면 꺼짐 방지, 확대 · 당겨서 새로 고침 · 뒤로 가기 막기, 안전 영역 · 화면 높이, 화면 어둡게.
- 서버: `/wpui/<wpweb.css | wpweb.js | pretendard.woff2>` 를 리모컨 · 도킹 · 카메라 · 편집기 서버가 함께 줌(정한 이름만). 리모컨 `/remote.css`, 카메라 `/cam.js` · `/cam.css`, 편집기 `/editor.js` · `/editor.css`.
- 색 뜻(조정자 결정 2026-11-28): **빨강 = 송출 중에만**(리모컨 표시창 왼쪽 띠 · 송출 중 순서 · 이름 자막 띄운 사람 · 카메라가 송출 중일 때), **노랑 = '다음'에 올린 것만**(리모컨 표시창 '다음' 글 · 순서 목록에서 [송출] 전 고른 줄), 고름 · 켜짐 · 탭은 회색, 오류 · 주의는 주황. 파랑 없음.

## 화면별

### 휴대폰 리모컨 (web/remote, `/` · OBS 도킹 `/dock`)
- 위: 연결 상태 · 큐시트 이름 · ··· 설정. 끊기면 주황 띠(지금 다시) + 표시창은 '끊김 · 마지막으로 받은 화면' 으로 흐리게, 저절로 다시 붙음(1 → 4초 간격), 붙으면 '다시 연결됨'.
- 표시창(LCD): 송출 중 / 글자 숨김 중(주황) / 송출 없음, 장 번호, 순서 번호 · 제목, 지금 글(크게, 줄 수 고정), '다음' 장 → 없으면 '다음 순서'(마지막 장에서 다음을 누르면 갈 곳) → 없으면 '마지막 장입니다'. 그림 · 악보 · 영상 · 카메라는 아이콘 + 이름(도킹은 그림 자체).
- 이름표 줄(1절 · 후렴 …): 지금 자리는 송출 중이면 빨강, 숨김이면 회색. 이름표 색은 조작 화면처럼 흐리게 섞은 밑줄.
- 탭 [순서 | 무대 | 구성 | 이름] (구성 · 이름은 있을 때만).
- 아래(엄지 자리): `[‹ 이전]` 작게 · `[다음 ›]` 크게(흰 송출 단추). 그 위 줄 양 끝에 `글자 숨김` · `모두 끄기`.
- 설정 판: 화면 어둡게 · 누를 때 진동(되는 기기만) · 화면 꺼짐 방지 상태 · 연결 끊기(PIN 지움) · 판 · 주소.
- 키보드(도킹 · 태블릿 자판): → PageDown Space = 다음, ← PageUp = 이전, Esc.
- 배치: 휴대폰 세로 / 작은 휴대폰(높이 760 미만은 조금 줄임) / 가로(왼쪽 표시창 · 단추, 오른쪽 목록) / 태블릿 760+(두 칸, 표시창이 늘어남) / 도킹(낮고 좁음).

### 휴대폰 카메라 (web/phone, https 37560 `/cam?k=`)
- 위: 상태 한 줄(크게) + 설명 한 줄, 세 단계 [1 카메라 허락 · 2 PC 와 연결 · 3 영상 보내기].
- 상태: 허락 기다림 → PC 와 연결하는 중 → 연결됨 · PC 에서 이 카메라를 고르세요(이름) → PC 로 보내는 중(받고 있지만 아직 안 나감) → **송출 중 · 예배당 / OBS**(빨강 테두리 · 표시, PC 의 '소스' 계산과 같은 `onAir`). 끊김 · 열쇠 바뀜은 주황.
- 미리보기 위: 송출 중 표시, 실제 해상도 · fps. 앞 카메라 미리보기만 거울처럼(보내는 영상은 그대로).
- 아래: 앞/뒤 카메라, [1080p | 720p], 'PC 카메라 목록에 보일 이름', 세로 영상 안내('가로로 눕히면 꽉 차게'), 배터리(안드로이드) · 발열 한 줄, 화면 꺼짐 방지 한 줄.
- 오류마다 고치는 법: 허락 거부(아이폰 aA → 웹 사이트 설정 / 안드로이드 자물쇠 → 권한) + [다시 시도], 다른 앱이 카메라 사용 중, 카메라 없음, 인앱 브라우저(카톡 등) → 기본 카메라로 QR, 열쇠 없음 · 바뀜.
- ··· 설정: **이 화면 가리기**(영상은 계속 보내고 휴대폰 화면만 검게 — 예배당 앞에서 빛나지 않게), 화면 어둡게, 알아 둘 것.
- 열쇠가 틀린 주소의 403 안내 화면도 같은 어두운 판(서버 `BAD_KEY_PAGE`, W6).

### 웹 편집기 (web/editor, 37545)
- 넓은 창: [큐시트 목록 | 순서 표 | 순서 넣기]. 1180 미만은 순서 넣기가 표 아래(머리에 [+ 순서 넣기]), 760 미만(휴대폰)은 목록 → 표 한 칸씩([‹] 로 목록).
- 위 막대: 큐시트 이름 · 저장 상태(불러옴 / 고친 것 있음 / 보내는 중… / 저장했습니다 · 시각 / 충돌 · 저장 안 됨 / 저장 못 함) · [다시 불러오기] · 흰 [저장 Ctrl S].
- 순서 표: 번호 · 종류(아이콘) · 제목(바로 고침) · 메모 미리보기 · ↑ ↓ 지우기 ⌄. 줄을 누르거나 Enter 로 펼쳐 부제 · 가사 · 부를 순서 · 장절 · 글 · 진행 메모. 고친 줄은 번호가 굵게, 새 줄은 점.
- 409: 덮어쓰지 않고 주황 띠 — [최신으로 다시 불러오기] · [내 것으로 덮어쓰기…](확인 뒤 최신 updatedAt 으로 다시 저장). 실패(끊김)는 '고친 것은 이 화면에 그대로' + [다시 저장].
- 10초마다 목록을 다시 받아, 열린 큐시트가 다른 곳에서 바뀌었으면 고친 것이 없을 때는 저절로 다시 불러오고, 있으면 미리 띠로 알림.
- 키보드: Ctrl+S 저장, ↑↓ 고르기, Enter 펼치기, Alt+↑↓ 옮기기, Delete 지우기(한 번 더 묻기), Ctrl+Z(입력칸 밖) 되돌리기, Esc, R 다시 불러오기. 지운 뒤 알림의 [되돌리기].
- 다른 큐시트를 누르면 불러오는 동안 옛 표를 비움(느린 Wi-Fi 에서 옛 표를 고치는 일이 없게 — 기존 e2e 가 실제 앱에서 잡은 틈).

## 서버 쪽 덧붙임 (약속은 그대로, 예전 화면은 모르는 필드를 지나침)

- 웹 영어 사전 '화면 구성' = Layouts (W7, 용어집).

## 실기 확인 필요 (이 PC 에서 볼 수 없는 것 — 코드는 대비함)

| 무엇 | 대비 | 볼 것 |
|---|---|---|
| 화면 꺼짐 방지 (리모컨) | 리모컨은 내부망 **http** 라 Wake Lock API 가 없다 → 소리 없는 32×32 영상(2.5KB, data: 주소)을 되풀이 재생. 첫 누름에서 시작 | iOS Safari 16+ · Android Chrome 에서 자동 잠금 30초로 두고 5분 동안 안 꺼지는지, 다른 앱 갔다 오면 다시 켜지는지 |
| 화면 꺼짐 방지 (카메라) | https(자체 서명) → Wake Lock, 거절되면 영상 방식 | 인증서 경고를 넘긴 페이지가 secure context 로 쳐져 Wake Lock 이 되는지 |
| 화면 높이 | `100dvh`, 없으면 `innerHeight` 로 `--vh` | iOS 주소창 접힘 · 펼침, 회전 뒤 아래 단추가 홈 막대 위에 붙어 있는지 |
| 안전 영역 | `viewport-fit=cover` + `env(safe-area-inset-*)` (시험은 `?safe=` 로 흉내) | 노치 아이폰 가로에서 노치가 단추 · 글을 가리지 않는지 |

## 못 한 것 · 넘길 것

- QR · PIN 을 보여 주는 조작 화면의 창(연결 → 휴대폰 리모컨 · 휴대폰 카메라 · 웹 편집기)은 F2 몫 — 웹 첫 화면 문구가 '연결 → 휴대폰 리모컨 창' 을 가리키므로 창 이름이 바뀌면 함께 바꿀 것(web/remote/index.html · web/editor/index.html · web/phone/cam.js · phonecam.rs `BAD_KEY_PAGE`).
- 편집기에서 끌어서 순서 옮기기는 넣지 않음(키보드 · 단추로 충분, 휴대폰 끌기는 굴림과 부딪침).
- 편집기 임시 저장(브라우저를 닫았다 열면 고친 것 되살리기)은 넣지 않음 — 닫기 전 경고만.
- 실제 리모컨 순서를 고쳐 차례를 바꾸면 송출 중 순서 번호가 어긋나 보일 수 있음(코어의 '송출 중 큐와 열린 큐 불일치' — CLAUDE.md 우선 검증 목록, 화면 문제가 아님).
